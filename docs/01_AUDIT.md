# Аудит приложенного MVP

Дата: 12 октября 2026. Исходник: `BALFEST_SITE_MVP.zip`.

## Сохраняем

- Простую статическую архитектуру: небольшой сайт без базы данных и серверного приложения.
- Тёмно-синюю палитру, тёплое золото, зимний Петербург и выразительную типографику.
- Последовательность «знакомство → направления → даты → участие → билеты → ответы и контакты».
- Тексты о роли сообществ, интересе для новичков и возможности найти своё направление.
- HTML-контент, семантику, FAQ на стандартных `details`, минимальное количество JS.

## Что требовало исправления

| Находка в MVP | Решение |
|---|---|
| Личная почта в Open Call и подвале | Убрана из нового публичного сайта; будущая почта скрыта до проверки |
| Ноябрьский старт продаж не подтверждён новым ТЗ | Заменён на «Билеты скоро в продаже» без даты |
| Суббота названа основным днём; пятнице и воскресенью назначены роли | Убраны неутверждённые сценарии; опубликованы только три даты |
| Open Call содержит дедлайны из старых материалов | Дедлайны не перенесены; включение утверждённой даты предусмотрено в настройках |
| Ссылка на старый адрес группы | Во всех публичных местах используется `vk.com/balfest` |
| На мобильном скрыта навигация | Добавлено доступное меню на стандартном `details` |
| Нет отдельного раздела партнёрам | Добавлен контактный блок без вымышленных логотипов |
| Свинг / джаз и отечественная программа не представлены отдельно | Добавлены отдельные направления; карточки раскрывают описание |
| Стрелки у направлений выглядят как ссылки, но не работают | Карточки стали настоящими раскрывающимися элементами |
| Canonical и sitemap появляются только после отдельной настройки | Создаются сразу для `https://balfest.ru/` |
| Первое изображение содержит надписи, повторяющие HTML | Сделана отдельная версия иллюстрации без надписей; важный текст в HTML |
| Вертикальный Open Call занимает много места | Использована новая горизонтальная афиша в исходном соотношении сторон |
| Данные распределены по HTML | Вынесены в `source/content.json` |
| Инструкция рассчитана на другого провайдера | Подготовлено размещение на Selectel / Ubuntu 24.04 |

Изменение организации исходников нужно для обслуживания и контроля публичных фактов. Production остаётся обычными статическими файлами. Исходный архив не изменён.

Визуальный аудит исходных изображений выполнен. Поведение исходной версии в браузере не проверялось: окружение браузерного предпросмотра оказалось недоступно.
