# БАГМУТ — сайт на FastAPI

Сайт Красноборского центра казачьей джигитовки «БАГМУТ».
Ветка bagmut создана от main репозитория balfest/balfest, коммит
53bbbf31f71e697290c94ef7240d6bc4d1de9c50. Сохранены архитектура
FastAPI + Jinja2, редактируемый JSON и выдача статики; оформление и
материалы адаптированы под центр.

Главная страница, шесть страниц направлений, проекты и выступления,
FAQ, контакты, карта и страница источников. Фильтр направлений
и мобильное меню работают без сторонних JS-библиотек.
Основное содержимое доступно без JavaScript.

## Быстрый запуск: Windows / Git Bash

Нужен Python 3.10 или новее. Откройте терминал в папке проекта:

~~~bash
git clone --branch bagmut --single-branch https://github.com/balfest/balfest.git bagmut
cd bagmut
py -3 -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
~~~

Откройте http://127.0.0.1:8000/ . Остановка сервера: Ctrl+C.
Если репозиторий уже клонирован, вместо клонирования:

~~~bash
git fetch origin
git switch bagmut
~~~

Если локальной ветки ещё нет, используйте git switch --track origin/bagmut.

## Docker

~~~bash
cp .env.example .env
docker compose up -d --build
~~~

Сайт доступен только с сервера по http://127.0.0.1:8000/ .
Для публичного доступа настройте HTTPS-прокси: пример находится в
deploy/Caddyfile.example. Укажите в нём свой реальный домен.
Для локального доступа с другого компьютера используйте туннель
или осознанно измените привязку порта.

В .env задайте SITE_URL — реальный HTTPS-адрес без пути, например
https://your-domain.example (это образец, не зарегистрированный домен).
После изменения окружения перезапустите контейнер:

~~~bash
docker compose up -d --force-recreate
~~~

Без SITE_URL сайт работает, но закрыт от индексации; canonical и
публичные URL не подставляются. В Python-запуске переменную нужно
передать через окружение процесса: приложение само .env не читает.
Не используйте --reload на публичном сервере.
Контейнер работает от отдельного пользователя, порт привязан к localhost,
есть healthcheck и конфигурация для автоматического перезапуска.

## Где менять содержимое

| Путь | Что находится |
|---|---|
| app/data/content.json | Тексты, направления, FAQ, контакты, ссылки и палитра |
| app/content.py | Проверка данных и контекст шаблонов |
| app/main.py | FastAPI, страницы, SEO-файлы и healthcheck |
| app/templates/ | HTML и разделы сайта |
| app/static/assets/ | Стили, JavaScript и собственная SVG-графика |
| docs/SOURCES.md | Источники, датировка и принятые решения |
| tests/test_app.py | Проверки HTTP, ссылок, SEO и экранирования |
| .github/workflows/bagmut.yml | Автоматические проверки и ZIP исходников |

JSON читается при каждом запросе. Новое направление добавляется в
programs; его id становится адресом /programs/id.
Ссылки в sourceIds должны соответствовать записям sources.
Шаблоны экранируют тексты; поля с URL принимают только HTTPS.
Не храните ключи или персональные данные в публичном JSON.

## Проверки

~~~bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
node --check app/static/assets/site.js
~~~

GitHub Actions запускает проверки на Python 3.10 и 3.12 при push в
bagmut и публикует ZIP точного коммита в артефактах успешного запуска.
Фактический результат смотрите на вкладке Actions.

## Содержание и статус

Материалы собраны из открытых публикаций по состоянию на 20.10.2026.
Архивные проекты отделены от действующих предложений. Непроверенные
актуальные цены, часы работы и расписание не выдумывались.
Запись ведёт напрямую в контакты центра: телефон, почта и VK.
Кнопка обсуждения события открывает почтовый клиент с черновиком письма;
сервер не принимает заявки и не отправляет сообщения.
На сайте нет обещания автоматически подтверждённой записи.

Конь и знак в шапке — собственная графика проекта, не заявленная как
официальный логотип организации. Фото и видео доступны по ссылкам
на публикации. Чужие фотографии из лент не скопированы в репозиторий.
Для Open Graph подготовлена SVG-заставка; для максимальной совместимости
превью в соцсетях замените её на утверждённый PNG/JPEG и обновите og_image.

Публикация на публичный сервер не выполняется автоматически.
