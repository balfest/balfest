# БАЛФЕСТ IV — сайт 2026

Рабочая статическая версия для собственного сервера. Даты: **4–6 декабря 2026**, Санкт-Петербург. Архив содержит готовые файлы и весь исходный проект. На сервере не нужны Node.js, Python, база данных или процесс разработки.

## Что загрузить на сервер

**Только содержимое `dist/`**. Это production-версия: HTML, CSS, JavaScript, изображения, robots.txt, sitemap.xml и страница 404. Инструкция для Ubuntu 24.04 / Selectel: [docs/02_SELECTEL.md](docs/02_SELECTEL.md). Конфигурация Caddy готова; Nginx — альтернативный вариант.

## Как обновлять

1. Откройте `source/content.json` в текстовом редакторе и измените нужные поля.
2. На своём компьютере из папки проекта выполните:

```bash
python3 scripts/build.py
python3 scripts/check.py
```

3. Загрузите обновлённое содержимое `dist/` на сервер.

Python 3.10+ нужен только для редактирования и сборки. Установка библиотек не нужна. Готовый `dist/` уже собран. Параметры и примеры: [docs/03_EDITING.md](docs/03_EDITING.md).

## Структура

| Папка / файл | Для чего |
|---|---|
| `dist/` | Готовый сайт для размещения |
| `source/content.json` | Тексты, даты, площадка, билеты, программа, студии, партнёры, контакты и палитра |
| `source/index.template.html` | Семантический HTML-шаблон |
| `source/media/` | Полноразмерные рабочие изображения |
| `static/assets/` | CSS, минимальный JS и оптимизированные изображения |
| `scripts/build.py` | Сборка на стандартном Python |
| `scripts/check.py` | Проверка сборки и защиты от публикации неподтверждённых данных |
| `deploy/` | Конфигурации веб-сервера |
| `docs/` | Аудит, развёртывание, обновления, отчёт и контроль перед релизом |

## Текущее состояние

Нет неподтверждённых цен, участников, партнёров, адреса и почты. Open Call — приглашение обсудить участие без опубликованного дедлайна. VK: `https://vk.com/balfest`. Продажи и аналитика отключены. `hello@balfest.ru` не выводится, пока `emailVerified` равно `false`.

Весь основной контент формируется в HTML при сборке и доступен без JavaScript. JS помогает закрывать меню, снимать истёкший Open Call и подключать Метрику, если владелец её включит. Техническая SEO-основа подготовлена; расширенный результат Event в поиске до уточнения площадки не гарантируется.

**Браузерная проверка и реальные ширины 320, 375, 390, 768, 1024, 1440 пока не подтверждены:** встроенное окружение предпросмотра не запустилось. Отчёт разделяет выполненные проверки и оставшиеся проверки перед публичным запуском: [docs/04_QA_AND_RELEASE.md](docs/04_QA_AND_RELEASE.md).
